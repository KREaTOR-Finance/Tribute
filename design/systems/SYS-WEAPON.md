# SYS-WEAPON — Weapon / Tool Feel & Timing

## Goal

Distinct weapon profiles (fist, sword, axe) with real timing differences — Culling tool identity.

## Independently judgeable

- Multiple profiles in data/code defaults
- Runtime switch (keys 1–3)
- Range/damage/windup differ meaningfully
- Visual attach point ready (mesh optional)

## Critic checklist

- [ ] Profiles not identical
- [ ] Switch is reliable
- [ ] Data-driven path exists
