# SYS-LOADOUT — Perks / Loadouts

## Goal
Meaningful pre-fight choices that change melee feel (Culling tool/perk fantasy).

## Scope (slice)
- 3 selectable perks at match start / keys 4–6 mid-slice for test
- Perks modify stamina, damage, windup, move speed via data
- Never replace melee identity with gun stats

## Critic bar
Distinct, data-driven, applied to live combat component.
