# SYS-META — Progression / Match Meta

## Goal
Light meta that rewards fights without diluting MeleeTest: kill/reset counters, match result, simple unlock flags for perks/weapons.

## Scope (slice)
- Match session stats (damage dealt, kills, deaths)
- End-of-match summary log + HUD line
- Unlock flags for second perk after first dummy kill

## Critic bar
Stats track real combat events; not fake placeholders.
